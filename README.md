# 🌍 Quiz Bandeiras

> Aplicativo Android desenvolvido em Java no Android Studio, criado para testar e desafiar os conhecimentos dos utilizadores sobre bandeiras de diferentes países de forma interativa e divertida.

---

## 🚀 Funcionalidades Principais

* **Modo de Jogo Interativo:** Ecrã de perguntas dinâmico com opções de escolha.
* **Sistema de Pontuação e Ranking:** Registo de desempenhos e pontuações dos jogadores (`RankingActivity`).
* **Design Nativo e Responsivo:** Interfaces estilizadas utilizando layouts do Android (`ConstraintLayout`, `CardView`).

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Linguagem:** Java (Programação Orientada a Objetos)
* **Plataforma:** Android SDK / Android Studio[cite: 10]
* **Interface:** XML (Layouts e componentes visuais)
* **Controlo de Versões:** Git & GitHub

---

## 📂 Estrutura do Projeto

* `app/src/main/java/com/example/quizbandeiras/`
  * `MainActivity.java` — Ecrã inicial do aplicativo.
  * `QuestionActivity.java` — Gestão da lógica das perguntas e respostas.
  * `RankingActivity.java` — Gestão da tabela de pontuações.
  * `Question.java` — Modelo de dados para as questões.
* `app/src/main/res/layout/` — Ficheiros XML de interface gráfica (`activity_main.xml`, `activity_question.xml`, `activity_ranking.xml`).
